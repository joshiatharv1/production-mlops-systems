# FastAPI MLOps Projects 🚀

This repository contains production-style Machine Learning systems built using Python, FastAPI, and modern MLOps practices.

The goal of this repository is to demonstrate how machine learning models can be trained, deployed, monitored, and served through scalable APIs.

---

# Tech Stack

Machine Learning

* Python
* Scikit-learn
* Pandas
* NumPy
* XGBoost / LightGBM

Backend APIs

* FastAPI
* REST APIs
* Async endpoints

MLOps

* Model versioning
* Model deployment
* Experiment tracking
* Pipeline automation

Infrastructure

* Docker
* PostgreSQL
* Redis
* Background workers
